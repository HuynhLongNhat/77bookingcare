# Project Setup Guide

## Client (ReactJS)
1. **Install Dependencies:**
   ```bash
   npm install
   ```
2. **Run the Development Server:**
   ```bash
   npm run dev
   ```

## Server
1. **Create Databases:**
   Create three databases in MYSQL workbench with the following names:
   - `77bookingcare_userservice`
   - `77bookingcare_doctorservice`
   - `77bookingcare_appointmentservice`

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Start the Server:**
   ```bash
   npm run start
   ```

---

### Notes:
- Ensure that your database credentials in the server configuration match your local setup.
- Make sure to have Node.js and a supported database (e.g., MySQL) installed on your system.
- For any issues, refer to the project documentation or contact the development team.

Happy coding!
